## Module 1：文字基礎美化 — 打造立體浮空文字

**操作步驟：**

1. 左側面板點「文字」分頁 → 「新增文字」底下的「預設文字」卡片 → 單擊卡片會浮現「+」→ 點「+」加入時間軸
2. 加入後畫面正中央會出現白字「預設文字」，時間軸多一條文字軌，右側面板自動切到文字屬性
3. 右側面板最上方文字內容框：全選（Ctrl+A）→ 貼上（Ctrl+V，剪貼簿內容需先用 PowerShell `Set-Clipboard` 放中文，CJK 不能模擬鍵盤打字）→ 改成「夜色浮光」
4. 「顏色」區塊往下有「文字」「線條」兩個數值框，**「線條」＝描邊寬度**：點擊框 → Ctrl+A 全選 → 貼上「8」→ 用 Tab 或點空白處確認（**不要按 Enter，會被還原**）
5. 往下捲（滑鼠滾輪）經過「對齊」「預設組樣式」「轉換（縮放/位置/平面旋轉）」，會看到「混合模式」核取方塊（預設已勾選）+ 底下「不透明度」滑桿，這就是書上講的「透明度」設定：拖曳滑桿或直接改數值框 → 設為 80%

**關鍵設定值：**

| 屬性 | 數值 |
| --- | --- |
| 文字內容 | 夜色浮光 |
| 線條（描邊） | 8 |
| 不透明度（混合模式） | 80% |

**踩坑 / 與教材的落差：**

- 這個版本的 CapCut「基礎」分頁**沒有獨立的「陰影」「發光」調整區塊**（書上的原教材提到陰影要調模糊度/距離/角度、還有發光效果），目前只找到 顏色／文字／線條（描邊）／混合模式（透明度）／轉換（縮放/位置/旋轉）。跟使用者確認後，**這次先用找到的三個效果（顏色、描邊、透明度）完成 Module 1，陰影/發光部分簡化略過**，可能是新版 UI 把陰影/發光整合進「花字」分頁的預設樣式包（Aa 色塊那排）裡，或藏在其他還沒試到的地方，之後有空再挖。
- CapCut 右側屬性面板很長，數值輸入框位置容易被捲軸位置搞混，操作時建議先用滑鼠滾輪小幅捲動＋每次截圖確認，不要憑記憶座標硬點。

**TTS 開場逐字稿：**

> 這是第8章「標題與文字的處理」的第一個 Module：文字基礎美化。我們要學的是怎麼把一段平凡的文字，變成有立體感、會發光的浮空文字。核心技巧包含四個：透明度的混合模式運用、描邊讓文字邊界更清楚、發光效果增加氛圍感，還有陰影的模糊度、距離、角度三個參數的搭配。這四個技巧疊加起來，就能做出質感很好的立體文字效果。

## Module 2：儲存文字預設 + 花字

**操作步驟：**

1. 沿用 Module 1 做好的「夜色浮光」文字圖層（顏色/線條8/不透明度80%），右側面板「基礎」分頁右下角有「儲存為預設組」按鈕，點下去
2. 畫面跳出 toast 通知：「文字預設組已儲存至 editor47823997's space」→ 代表這組樣式已存進個人風格庫，之後在「文字」分頁左側「您的」底下應該找得到，下次要用同樣風格的文字直接套用不用重調
3. 右側面板切到「花字」分頁（在「基礎」「泡泡音」旁邊）→ 跳出一個「CapCut 行動版不提供品牌套件」的提示視窗（跟這次操作無關，純粹雲端同步相關提示，點「確定」關掉即可）
4. 花字分頁載入後是一整排「ART」預覽縮圖網格，**這裡就是重大發現**：很多花字樣式本身就內建了發光/光暈/陰影效果（紫色光暈、青色光暈、金色描邊發光等），**證實 Module 1 找不到的獨立「陰影」「發光」調整區塊，在這個版本的 CapCut 是被整合進「花字」預設樣式裡**，不是拆成獨立參數給你調，而是設計師做好一整包直接套用
5. 選一個紫色發光樣式套用到「夜色浮光」→ 文字瞬間變成白色粗體字+紫色光暈背景框+白色描邊，立體浮空感很明顯，效果比 Module 1 手動調的三個參數更搶眼

**關鍵操作提醒：**

- 「儲存為預設組」按鈕在**每個分頁（基礎/花字）右下角都各自有一個**，儲存的是「當下這個分頁呈現的完整樣式」
- 花字套用是**單擊縮圖就直接套用**（不是先預覽再按+的兩段式），跟 Module 1 的「預設文字」卡片行為不同，要留意這兩種素材庫的互動邏輯不一樣
- 花字面板頂部有搜尋框（搜尋文字特效/樣式）+ 分類標籤（熱門/經典/夏日/新增/大熱），要精準找特定風格可以用搜尋，這次示範用瀏覽直接挑，沒特別搜尋關鍵字

## Module 3：文字模板

**操作步驟：**

1. 左側面板「文字範本」分頁：分類清單很多（熱門/KATSEYE/蜘蛛/夏日/經典/新增/大熱/Minions/Free Fire...，很多是跟熱門 IP/節日聯名的限定款），用「熱門」瀏覽
2. 縮圖 hover 會浮現星號（收藏）+「+」，點「+」直接加入時間軸——這裡跟「花字」不一樣：花字是單擊縮圖直接套用到「當前選取的文字圖層」，文字範本是點「+」**新增一條獨立文字軌**，不會覆蓋原本的「夜色浮光」圖層
3. 加入後右側面板自動切到「基礎」分頁，最上面「1 段落」文字框顯示範本原始文字（這次選到的範本原文是越南文「Đi não」）
4. 二次微調：全選（Ctrl+A）→ 貼上「深夜漫步」→ 完成文字內容替換，範本原本的動畫/配色/排版樣式都保留，只換文字內容

**關鍵提醒：**

- 文字範本的分類清單很多是跨語言（泰文/越南文/韓文/日文）的社群熱門款，套用前文字內容通常要換成自己的語言，這步驟不能省
- 這次範本圖層跟花字圖層剛好疊在同一個時間點+同個畫面位置，靜態截圖只看得到其中一層，實際剪輯上通常會錯開時間軸位置或調整座標避免重疊，本次 demo 重點在示範套用+微調流程，沒特別處理排版避讓

## Module 4：文字動畫三階段（入場/出場/迴圈）

**操作步驟：**

1. 時間軸點選「夜色浮光」文字片段 → 右側面板頂部切到「插入動畫」分頁（跟「文字」分頁同一排，在「文字/插入動畫/追蹤/文字轉語音/AI虛擬替身」這幾個 tab 裡）
2. 「插入動畫」面板本身又分三個子分頁：**進場｜退場｜循環播放**，跟書上講的三階段完全對應，不用額外找
3. 進場：選「打字機II」→ 底下有「時長」數值框，預設 0.5s，這次沿用預設值
4. 退場：選「漸隱閃爍」→ 一樣有時長控制，可以左右各自獨立設定
5. 循環播放：選「閃動」（呼應「浮光」主題，讓文字停留期間有忽明忽暗的光感）→ 底下有「速度」滑桿控制閃動快慢

**關鍵設定值：**

| 階段 | 選用動畫 | 時長 |
| --- | --- | --- |
| 進場 | 打字機II | 0.5s |
| 退場 | 漸隱閃爍 | 0.5s |
| 循環播放 | 閃動 | 預設速度 |

**關鍵提醒：**

- 三階段是**各自獨立的分頁**，不是同一個清單三選一，可以進場選A、退場選B、循環選C自由組合
- 套用動畫後時間軸上的文字片段會出現視覺標記（片段左右兩端會有動畫圖示），一眼就能看出這段文字有沒有加動畫
- 每種動畫選下去，播放器會立刻跳到對應的時間點自動預覽（例如選退場動畫，播放頭會跳到片段尾端），方便直接看效果不用手動拖時間軸

## Module 5：文字轉語音

**操作步驟：**

1. 時間軸點選「夜色浮光」文字片段 → 右側面板頂部切到「文字轉語音」分頁（跟「文字/插入動畫/追蹤/文字轉語音/AI虛擬替身」同一排）
2. 語音清單分類：熱門/新增/TikTok/中文/旁白，預設是「熱門」（大多是日文/英文/西班牙文語音包），切到「中文」分類才找得到適合中文文案的聲音
3. 中文分類選項：亲切女声、Calm Host、紫薇、玲玲姐姐、溫柔姐姐、甜美解說、小蘿莉、治癒男聲⋯這次選「溫柔姐姐」，氣氛跟「夜色浮光/深夜漫步」的浪漫夜晚主題搭
4. 選好聲音後點右下角「產生語音」→ 跳出「正在產生語音...」處理中視窗（有取消按鈕）→ 完成後**時間軸自動多一條新的音訊軌**，標籤是「夜色浮光　文字轉語音」，帶波形顯示
5. 選取這條新音訊軌，右側面板變成聲音專屬設定：基礎（音量/淡入/淡出/響度標準化/降噪等）、變聲、速度 三個分頁

**關鍵提醒：**

- 文字轉語音是**吃文字圖層當下的內容**去生成配音，所以要先確定文字內容（本例是「夜色浮光」）是最終版才生成，改了文字內容舊配音不會自動更新，要重新按一次「產生語音」
- 生成結果是獨立的音訊圖層，跟原本的文字圖層是分開的兩個東西，可以各自調整位置/音量，互不影響
- 「中文」分類底下其實還混雜了不少日文命名的聲音（清らかな正太、穏やかな町娘等），語音風格是跨語系分享的資源庫，不是嚴格照語言分類，選的時候建議先點下去試聽再定案（這次示範沒有逐一試聽，直接依名稱語感挑選）

## Module 6：封面設計

**操作步驟：**

1. 時間軸左側、影片軌旁邊有個獨立的「封面」按鈕（跟一般文字/音訊軌操作分開，不在右側屬性面板裡）
2. 點下去會彈出「選取封面」小視窗：可以「從影片中選取」（下方有整支影片的縮圖捲軸，直接點選某一幀）或切到「本機」上傳外部圖片
3. 選好基底畫面後，點「編輯封面」進入**獨立的「封面設計」工作室**（跟主編輯器是完全不同的介面，左上角麵包屑會顯示「封面設計」）
4. 封面設計工作室左側面板：文字（新增標題/副標題/內文文字）、圖片、形狀、範本（按分類瀏覽：推薦/影音部落格/旅行等）——右側還有一個「AI 幫您設計」聊天助理，可以用文字描述直接生成整套封面
5. 點「新增標題」→ 畫面正中央出現大字體白色標題文字框（預設文字「新增標題」），可以拖曳調整位置/大小
6. 編輯完點右下角「儲存」→ 跳出「載入中」處理視窗 → 完成後回到主編輯器，時間軸「封面」按鈕縮圖會更新成剛剛設計的畫面

**踩坑（這次卡最久的一關）：**

- **封面文字內容修改失敗，試了 4 種方式都沒成功**：雙擊進入編輯模式（視覺上有游標出現）、pywinauto 全選+貼上、pywinauto 全選+Delete、SendInput 底層 Backspace，文字始終停留在預設的「新增標題」。研判原因：這個封面設計工作室是獨立的 canvas 渲染介面（類似 Figma/Canva 那種畫布），而不是一般的 Win32 輸入框；本次自動化操作每次下指令都要開一個新的 Python/PowerShell 子行程，這個切換空檔似乎會讓 canvas 內的文字編輯焦點掉出去，導致鍵盤事件送不進去
- **這次示範沒有解決這個問題，是接受現況直接存檔**：封面標題文字維持預設的「新增標題」，沒有換成想要的標題文案。功能流程本身（開啟封面編輯器→選底圖→加文字框→存檔）完整跑過一次，只是文字內容客製化這步驟卡住了
- 如果之後要真的排除這個問題，可以試試看：不要中途開新的 Python 子行程送鍵盤事件，改成單一個 Python process 裡連續執行「雙擊→全選→打字」不中斷；或是改用滑鼠拖曳游標選取文字範圍再打字，跳過鍵盤 Ctrl+A 這條路徑
- 另外這次也重新踩到「CapCut 渲染卡死」的已知問題（memory 已記錄的踩坑）：點了 3 次「封面」按鈕都沒反應（甚至跳出「畫面載入中，請稍候」但一直沒完成），最後用**完全關閉 CapCut 進程再重啟**解決，重啟後專案內容（4 個 Module 的所有素材/文字/動畫/配音）完全沒有遺失，證實 CapCut 的自動儲存機制在渲染卡死時仍然可靠

## Module 7：進階黑魔法 — 文字穿插人物背後

**操作步驟：**

1. 時間軸點選背景影片片段「男人送女人回家的路上」→ `Ctrl+C` 複製 → 把播放頭移到 00:00:00 → `Ctrl+V` 貼上
2. **關鍵發現**：直接 `Ctrl+V` 貼上（不用刻意找「新增軌道」按鈕），CapCut 會自動偵測到同一時間點已有素材佔用，**自動在上方建立一條新的視訊軌**放複製的片段，不會覆蓋原本的影片
3. 貼上後的複製片段預設落在「文字軌」和「原始影片軌」中間（軌道順序由上到下：文字×2 → 複製影片 → 原始影片）。用滑鼠**慢速分段拖曳**（mouse down → 多步小幅移動、每步間隔約 80ms → mouse up，一次拖曳到位會靜默失敗），把複製片段拖到**最上層**、兩條文字軌的上方
4. 拖曳完成後最終軌道順序（由上到下）：複製影片（頂層）→ 文字軌「深夜漫步」→ 文字軌「夜色浮光」→ 原始影片（底層）→ 音訊軌
5. 選取最上層的複製影片片段 → 右側屬性面板切到「移除背景」分頁（跟「基礎／移除背景／遮罩轉場／潤飾」同一排，Module 1 踩坑提到的「陰影/發光藏在哪」旁邊那排分頁）
6. 勾選「自動移除」（帶 AI 圖示的核取方塊）→ 立即觸發 AI 智慧摳像運算，時間軸片段上會顯示「正在套用 自動摳圖... N%」進度、右側面板顯示「處理中N%」→ 等待處理到 100%（本次約 15 秒完成，5 秒素材算快的）
7. 處理完成後把播放頭從 00:00:00 移到時間軸中段（例如 00:00:02:02）驗證效果：畫面中兩人（男女背影）明顯疊在文字「深夜漫步」前方，文字被人物身形局部遮擋，產生「文字穿插在人物背後」的立體漂浮感——效果成功

**關鍵設定值：**

| 步驟 | 設定 |
| --- | --- |
| 疊加層數 | 3 層（頂層摳像人物 / 中層文字×2 / 底層原始影片） |
| 摳像模式 | 移除背景 → 自動移除（AI 智慧摳像，非手動色度鍵） |
| 摳像處理時間 | 約 15 秒（5 秒素材） |

**踩坑 / 與教材的落差：**

- **`Ctrl+C`/`Ctrl+V` 是這個技巧最快的複製疊層方式**，不需要繞去找「建立複合式片段（子專案）」（Alt+G）這個右鍵選單選項——那個功能是把多個片段包成一個子專案素材，跟這裡要的「同一素材疊兩層」是不同用途，容易選錯（本次示範一開始也差點被這個選項誤導，後來確認直接 `Ctrl+V` 更直覺有效）
- **拖曳片段調整軌道順序時，一定要慢速分段拖曳**：本次示範一次到位的拖曳（mouse down → 直接 SetCursorPos 到終點 → mouse up）在其他 Module 已知會靜默失敗，Module 7 改用「分 15 步、每步間隔 80ms」的漸進式拖曳才成功把複製片段從中間層移到最上層
- **重大踩坑（黑底問題）**：套用摳像後，畫面中「非人物、非文字」的區域顯示**純黑色**，而不是原始街景背景（暖黃燈光的廣場/建築）。推測原因：Module 3 套用的「深夜漫步」文字範本本身是一個**帶有不透明背景色塊的動態圖形範本**，不是單純的透明背景文字——範本圖層本身就不透明，蓋住了它下方的原始影片，導致最終合成只看得到「摳像人物」+「範本的黑底文字圖案」，看不到原始街景。**如果要做出「文字浮在原始場景中、人物穿插其間」的完整效果**，中間層應該用**單純文字（無背景圖案的花字或基礎文字），不要用帶滿版圖形背景的文字範本**，這點教材原文沒有特別提醒，是本次示範才發現的落差
- 這個技巧的核心原理總結給沒摳過的人：**同一份影片疊兩份，上面那份摳掉背景只留人物，中間夾一層文字，人利用人物不透明、文字被上層人物遮擋的視覺錯覺，做出「文字穿插在人物背後」的立體感**——不是真的有 3D 深度運算，純粹是圖層疊放順序的障眼法
- AI 智慧摳像的運算是**非同步背景處理**，套用當下畫面不會立即改變，要等進度跑完（時間軸片段上有百分比可以看），操作時不要在還在跑進度時就急著做下一步

**TTS 開場逐字稿：**

> Module 7，進階黑魔法：文字穿插人物背後。這是整份教材最難、也最吸睛的一個技巧。原理是把同一段影片疊成三層：最底層是原始背景影片，中間夾一層文字，最上層再疊一份複製的影片，並對這份複製影片套用智慧摳像，只保留人物、去掉背景。這樣一來，人物走在文字前面，但文字周圍的背景會被文字蓋住，視覺上就產生了文字穿插在人物背後、若隱若現的漂浮效果。
