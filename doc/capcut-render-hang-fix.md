# CapCut 播放器渲染卡死 — 診斷與修復記錄

- 日期：2026-08-12
- 受影響專案：`前言概念-關鍵幀遮罩字幕`（第1章 live demo 專案）
- CapCut 版本：9.2.0.3931

## 症狀

播放器畫面完全空白，只在畫面正中央固定顯示兩個小色點（青色＋桃紅色，緊鄰不動）。無論拖動播放頭到哪個時間點、切換選取哪個片段、甚至完全關閉專案再重新開啟，這兩個色點的螢幕位置都紋風不動。

## 排除的可能原因

- 遮罩設定錯誤：檢查該片段「調整 → 遮罩轉場」，確認遮罩本身設定正常（修好後證實畫面上其實有一個圓形遮罩套用在人物影片上）
- Proxy 代理檔設定：詳細資料面板顯示「Proxy：已關閉」，非原因
- 磁碟空間不足：C 槽尚有 52.8GB 可用，非原因
- 素材離線／遺失：時間軸縮圖正常顯示，素材檔案存在

## 根本原因

CapCut 的渲染／GPU 處理進程卡死（凍結），畫面上那兩個色點其實是卡住的「載入中」動畫圖示，不是任何實際素材內容。判斷依據：色點位置在任何操作下都固定不變，且**單純關閉專案、重新開啟同一個專案並不會修復**，代表問題發生在 App 層級的渲染管線，不是單一專案的狀態損壞。

## 修復方式

**只有「完全結束 CapCut 所有背景進程，再重新啟動整個應用程式」才有效**：

```powershell
# 1. 強制結束所有 CapCut 進程（多進程架構，主進程+GPU/渲染子進程）
Get-Process -Name CapCut -ErrorAction SilentlyContinue | Stop-Process

# 2. 重新啟動
Start-Process "C:\Users\<使用者>\AppData\Local\CapCut\Apps\<版本號>\CapCut.exe"
```

重啟後重新開啟專案，畫面即恢復正常渲染（遮罩、貼圖動畫、文字疊加、播放/暫停皆正常）。

## 下次遇到同樣症狀時的處理

1. 先確認是否為此症狀：畫面固定顯示小色點、位置不隨操作改變
2. **不用**重建專案或懷疑自己的編輯內容壞掉——CapCut 有自動儲存，素材與編輯都還在
3. 直接完全結束 CapCut（工作管理員或右鍵工作列圖示→結束工作），再重新開啟即可
4. 若使用者自行操作：工作管理員 → 結束所有 CapCut 相關工作 → 重新啟動 CapCut
