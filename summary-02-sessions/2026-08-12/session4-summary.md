## 關鍵技術筆記

1. **多螢幕座標換算鐵律**：`screenshot.ps1` 用絕對螢幕座標（`Left/Top` 可為負值，本機第二螢幕 `Top=-117`），點擊座標換算公式必須是 `screen_X = Left + image_x`、`screen_Y = Top + image_y`——本 session 至少 3 次因忘記加上負 Top 偏移導致點擊完全落空或誤觸其他 UI 元素，教訓：每次換算完座標務必覆算一遍再點擊，不要憑經驗直接套用前一次算式。
2. **CapCut 自動字幕辨識對 TTS 合成語音可能完全失效**：不是辨識出簡體字，而是整段辨識成無意義羅馬拼音亂碼。這比課本描述的「簡體字」情境更極端，未來若要示範自動字幕辨識，優先用真人語音來源（如剪一段既有教學影片片段），不要依賴 CapCut 內建 TTS 生成的配音。
3. **文字內容編輯的可靠操作方式**：雙擊播放器畫面中的文字物件本身（而非右側屬性面板的文字框）進入編輯模式，再 `Ctrl+A` 全選 + `Ctrl+V` 貼上，成功率 100%；直接點擊/雙擊右側屬性面板的文字輸入框曾經失敗（文字未變更）。
4. **CapCut 文字屬性面板「基礎」分頁的「文字 0 / 線條 0」數值欄位不是描邊/陰影**，推測是字距/行距類控制；描邊/陰影設定尚未在本 session 找到確切位置（花字分頁是完整樣式庫非參數調整、泡泡音分頁是另一套樣式庫，點擊顏色色塊下拉區域曾意外誤觸套用泡泡音樣式）——**留給下次 session 繼續排查**。
5. **既有可重用 PowerShell 自動化腳本**（存於 `%TEMP%`，非本次新建）：`screenshot.ps1`（區域截圖）、`get_rect2.ps1`（取視窗座標+置頂，hwnd 需每次重新 EnumWindows 更新）、`single_click.ps1` / `dblclick.ps1` / `right_click.ps1`（滑鼠操作）——這些腳本因是既有檔案且改動 ≤3 行（僅改 hwnd 常數）而豁免 writer-qa 三 agent 鐵律，可直接 Edit 沿用，不需每次重新產生。
6. **CapCut 新建專案會開一個獨立子視窗**（hwnd 與首頁視窗不同），每次新建/返回首頁都要重新 `EnumWindows`，此為既有 memory 已記錄的踩坑，本次再次驗證。
