# Kindle 45｜AI影片製作工具箱

《AI影片製作工具箱：AI繪圖合成×智慧編輯剪片×ChatGPT 5文案生成全攻略(第四版)》全書 15 段落的原始素材與 NotebookLM 生成產物。

## 目錄結構

```
pdf/                   15 個章節 PDF（原始書籍內容，按段落切分）
slides/                15 個 NotebookLM 生成簡報（PPTX）
audio/                 15 個 NotebookLM 生成語音摘要（M4A）
srt/                   15 個語音摘要逐字稿（SRT，含時間軸）
txt/                   15 個語音摘要逐字稿（純文字，與 srt/ 同內容）
doc/                   剪映操作技術文件（踩坑紀錄、流程 handoff）
doc/demo-recordings/   各章 live demo 的截圖與筆記
fonts/                 文泉驛微米黑－簡轉繁（剪映顯示中文用）
summary-02-sessions/   各次 session 工作紀錄（依日期分資料夾）
```

### doc/ 現有文件

| 檔案 | 內容 |
| --- | --- |
| `capcut-tts字幕對齊-2026-08-15.md` | TTS 語音的字幕逐字對齊（靜音偵測＋DP，不用語音辨識） |
| `capcut-螢幕錄影標註-handoff-2026-08-14.md` | 螢幕錄影標註（紅框／馬賽克／追蹤）交接文件 |
